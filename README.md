<h1 align="center">EditX – Real-Time Collaborative Text Editor</h1>

EditX is a powerful, real-time collaborative rich text editor built with [Next.js](https://nextjs.org/), [Tiptap](https://tiptap.dev), and [Liveblocks](https://liveblocks.io). It allows multiple users to edit the same document simultaneously, see each other's cursors, and collaborate more effectively — all in your browser.

---

## 🚀 What Makes EditX Special?

- ⚡ **Live Collaboration** – Edits are instantly reflected for all users
- ✍️ **Rich Text Editing** – Format text with bold, italic, headings, lists, and more
- 🧠 **User Presence & Cursors** – See who’s online and where they're editing
- 🔐 **Environment-secure** – Powered by Liveblocks authentication
- 🔄 **State Persistence** – Changes are saved automatically

---

## 🧰 Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS
- **Editor Framework:** Tiptap
- **Real-time Engine:** Liveblocks
- **Deployment Ready For:** Vercel, CodeSandbox

## 🛠️ Getting Started

To run EditX locally on your machine:

### 1. Prerequisites

- [Node.js](https://nodejs.org/) installed
- A free [Liveblocks](https://liveblocks.io) account

### 2. Clone the Repository

```bash
git clone https://github.com/juned-mansuri/editx
cd editx
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the root of the project and add your Liveblocks secret key:

```
LIVEBLOCKS_SECRET_KEY=your-liveblocks-secret
```

You can find this key on the [Liveblocks dashboard](https://liveblocks.io/dashboard/apikeys).

### 5. Start the Development Server

```bash
npm run dev
```

Visit `http://localhost:3000` to use your collaborative editor.
